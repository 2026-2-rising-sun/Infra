# tests/e2e

**상태: 골격만. 사용 툴 미정.**

여러 서비스를 가로지르는 시나리오(회원가입 → 상품 조회 → 주문 → 알림 수신)를 검증할 자리다.
단일 서비스 내부 테스트는 Backend 레포에 있고, 여기에는 **서비스 경계를 넘는 것만** 둔다.

## 정해야 할 것

- 도구: Playwright(Frontend 포함 브라우저 레벨) / REST 클라이언트 기반(백엔드 API 레벨) / 둘 다
- 실행 대상: `local/docker-compose.yml` + 로컬 기동 서비스 vs `k8s/overlays/dev` 배포본
- 실행 시점: PR 마다 / 머지 후 / 야간
